# Sözlük

| Terim | Açıklama |
| --- | --- |
| **NGFW** | Yeni nesil güvenlik duvarı (Next-Generation Firewall); uygulama, kullanıcı, IPS ve SSL incelemeyi tek cihazda yapar. |
| **UTM** | Güvenlik duvarı, antivirüs, web filtre, VPN ve IPS'i tek kutuda toplayan çözüm; küçük ofisler için. |
| **WAF** | Web uygulaması güvenlik duvarı; SQL injection, XSS gibi HTTP saldırılarını engeller. |
| **ISFW** | İç segmentasyon güvenlik duvarı; ağın iç bölümlerini (doğu-batı trafiği) birbirinden ayırır. |
| **Threat protection throughput** | IPS, antivirüs, uygulama kontrolü ve SSL inceleme açıkken cihazın taşıyabildiği gerçek trafik. |
| **HA (Active-Passive)** | İki cihazdan biri çalışır, diğeri yedekte bekler; arızada oturum kaybı olmadan devralır. |
| **LACP (802.3ad)** | Birden çok fiziksel kabloyu tek mantıksal hat gibi birleştiren protokol. |
| **VLAN (802.1Q)** | Aynı fiziksel ağı mantıksal ağlara bölen etiketleme. |
| **Güvenlik bölgesi (zone)** | Kural yazarken kullanılan, VLAN'ların güven seviyesine göre gruplanması. |
| **DMZ** | İnternete açık sunucuların iç ağdan ayrı tutulduğu bölge. |
| **SD-WAN** | Birden çok hattı ölçülen kaliteye göre kullanıp arızada otomatik geçiş yapan yönlendirme. |
| **BGP** | İnternet ve hatlar arası dinamik yönlendirme protokolü. |
| **IPsec / IKEv2** | Şubeler arası şifreli tünel (VPN) protokolü. |
| **AES-256-GCM, SHA-384, DH 20** | Tünelde kullanılan şifreleme, bütünlük ve anahtar değişimi algoritmaları. |
| **QoS / DSCP** | Trafiği sınıflara ayırıp öncelik veren mekanizma ve paket etiketi (EF, AF41 gibi). |
| **Per-IP shaper** | Kişi başı hız ve oturum sınırı. |
| **CGNAT / PBA** | Çok kullanıcının az sayıda genel IP'yi paylaşması; port bloğu tahsisi her kullanıcıya sabit port aralığı verir. |
| **NP7** | FortiGate'in ağ işlemcisi (ASIC); NAT ve paket işlemeyi donanımda hızlandırır. |
| **802.1X / RADIUS / RSSO** | Kullanıcı kimliğiyle ağa giriş; RSSO bu kimliği güvenlik duvarına taşır. |
| **Eduroam** | Üniversiteler arası ortak kablosuz ağ kimlik doğrulama federasyonu. |
| **ULAKNET** | Türkiye akademik omurga ağı (ULAKBİM). |
| **User-ID / App-ID** | Kuralı IP yerine kullanıcı grubuna ve uygulamaya bağlama (Palo Alto terimleri). |
| **EDL** | Dinamik harici liste; engellenecek IP'leri güvenlik duvarına otomatik besler. |
| **DLP** | Veri sızıntısı önleme; kaynak kod, kişisel veri gibi içeriğin dışarı çıkmasını engeller. |
| **SSL inceleme** | Şifreli HTTPS trafiğini çözüp tarayan işlem; KVKK/GDPR nedeniyle bazı kategoriler muaf tutulur. |
| **SIEM** | Tüm logları toplayıp ilişkilendiren ve alarm üreten sistem. |
| **SOAR** | Alarma otomatik müdahale (ör. IP engelleme) sağlayan otomasyon. |
| **SOC / NOC** | Güvenlik operasyon merkezi / ağ operasyon merkezi. |
| **Tier-1/2/3** | SOC analist kademeleri: triyaj, inceleme/müdahale, ileri analiz ve tehdit avcılığı. |
| **EDR / NDR** | Uç nokta / ağ tespit ve müdahale çözümleri. |
| **NetFlow / IPFIX** | Ağ akışı istatistiği; hattı kimin ne kadar kullandığını gösterir. |
| **MTTD / MTTA / MTTR** | Ortalama tespit / üstlenme / müdahale süresi. |
| **MITRE ATT&CK** | Saldırgan tekniklerinin standart sınıflandırması. |
| **Playbook** | Bir olay türü için önceden yazılmış müdahale adımları. |
| **CAB / 4 göz ilkesi** | Değişiklik onay kurulu; kuralı hazırlayan ile yayınlayan farklı kişi. |
| **Zero Trust** | Hiçbir bölgeye varsayılan güven vermeyen, her erişimi doğrulayan tasarım. |
| **5651** | Türkiye'de internet erişim kayıtlarının zaman damgalı tutulmasını zorunlu kılan kanun. |
| **KVKK** | Türkiye kişisel verilerin korunması kanunu. |
| **UK-GDPR** | Birleşik Krallık kişisel veri koruma rejimi. |
| **OT** | Operasyonel teknoloji; üretim ve endüstriyel cihazlar. |
| **HPC** | Yüksek başarımlı hesaplama kümesi. |
